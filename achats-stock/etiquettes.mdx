## Une étiquette pour un produit

Menu **Produits** → **Imprimer des codes-barres**. Choisissez **le produit** et **combien d'étiquettes**, puis **Imprimer**. Vous pouvez aussi passer par le bouton **étiquettes** sur la ligne du produit.

## Plusieurs produits d'un coup

Cochez les produits dans la liste, tapez le nombre pour chacun, puis **Imprimer n série(s) d'étiquettes**.

## Le format

Dans la fenêtre d'impression, choisissez le **Format** :

- rouleaux : 40×30 (par défaut), 50×30, 50×25, 50×20, 60×40, 70×50, 80×50, 30×20 mm, ou **Autre taille…** ;
- **Feuille A4** pour une imprimante normale.

**Rotation** : Aucune, 90° ou 90° dans l'autre sens. MonPOS retient votre choix sur cet ordinateur.

<Tip>
  Dans la fenêtre d'impression du navigateur : **même taille de papier** que l'étiquette, **marges : aucune**, **échelle : 100 %**.
</Tip>

<Info>
  Le code-barres est créé à la première impression puis **ne change plus jamais**. Une étiquette imprimée aujourd'hui et une imprimée l'an prochain scannent le même article.
</Info>
