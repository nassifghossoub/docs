## Ce que MonPOS attend dans le tiroir

| | |
|---|---|
| Fond de caisse | l'argent mis à l'ouverture |
| **+** Ventes espèces | dont les dettes encaissées en espèces |
| **−** Remboursements | rendus au client en espèces |
| **−** Dépenses | payées avec l'argent du tiroir |
| **= Attendu en caisse** | ce que vous devez trouver |

Les paiements par carte, Wave, Orange Money ou MTN, et les ventes à crédit, **ne sont pas dans le tiroir**. Ils n'entrent donc pas dans « Attendu en caisse ».

## Clôturer

<Steps>
  <Step title="Comptez les billets et les pièces">Sans regarder le montant attendu.</Step>
  <Step title="Touchez « Clôturer le poste »">Le bouton rouge en haut de la caisse, ou dans le menu **Postes**.</Step>
  <Step title="Tapez votre comptage dans « Espèces comptées »">Puis **Clôturer le poste**.</Step>
</Steps>

Le résumé **Poste fermé** s'affiche :

- **Doit être en caisse**, avec le compté et l'**écart** : vert s'il y a plus, rouge s'il manque ;
- le détail par moyen de paiement ;
- **Vendu à crédit** : « dû, pas encaissé — il n'est pas dans la caisse ».

**Imprimer** pour garder une trace papier, puis **Fermer**.

<Check>Un écart de 0 : la caisse est juste.</Check>

<Tip>Tous les postes passés, avec leurs écarts, sont dans le menu [Postes](/argent/postes).</Tip>
