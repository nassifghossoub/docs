Un **poste**, c'est la période pendant laquelle une caisse est ouverte : du matin jusqu'au comptage du soir. MonPOS ne peut pas encaisser sans poste ouvert.

<Steps>
  <Step title="Appuyez sur le bouton POS">
    Le gros bouton vert en haut de l'écran.
  </Step>
  <Step title="Comptez le tiroir">
    Si aucun poste n'est ouvert, MonPOS affiche **Aucun poste ouvert**. Comptez l'argent déjà présent dans le tiroir (la monnaie).
  </Step>
  <Step title="Tapez ce montant dans « Fond de caisse »">
    Puis **Ouvrir le poste**. Vous pouvez vendre.
  </Step>
</Steps>

<Info>
  Le poste appartient à la **caisse**, pas à la personne. Si un collègue a déjà ouvert le poste de cette caisse, vous travaillez dans le même poste et MonPOS ne redemande rien.
</Info>

<Warning>
  Tapez le vrai montant : ouvrir un poste, c'est un comptage. MonPOS s'en sert le soir pour calculer ce qui **doit** être dans le tiroir.
</Warning>

On peut aussi ouvrir le poste depuis le menu **Postes** : voir [Postes](/argent/postes).
