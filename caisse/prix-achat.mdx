Le bouton **Prix d'achat**, en haut de la caisse, affiche le coût de chaque article à côté de son prix de vente. Il est protégé par un **code PIN** pour que les clients et les caissiers ne le voient pas.

<Steps>
  <Step title="Touchez « Prix d'achat »">La fenêtre **Code PIN** s'ouvre.</Step>
  <Step title="Tapez le code (4 à 8 chiffres)">Puis **Afficher**. Les tuiles montrent maintenant le prix d'achat.</Step>
  <Step title="Pour les cacher">**Masquer les prix d'achat**. Ils se cachent aussi dès que la page est rechargée.</Step>
</Steps>

<Info>
  Le code se règle dans **Paramètres → POS → Code PIN « Prix d'achat »**. Le **même code** déverrouille le [Tableau de bord](/rapports/tableau-de-bord). Sans code défini, le bouton n'apparaît pas, sauf pour l'administrateur, qui est invité à en créer un.
</Info>

Seuls les rôles qui ont le droit « Afficher les prix d'achat à la caisse » voient ce bouton : par défaut, l'administrateur et le gérant.
