Après chaque vente, le ticket s'affiche avec : le nom de la boutique, le n° de vente, la date, le client, le vendeur, les lignes, le sous-total, les remises, la taxe, le total, les paiements et « Merci ! ».

- **Imprimer** : imprime le ticket.
- **Nouvelle vente** : ferme le ticket et vide la caisse pour le client suivant.

## Avec une imprimante thermique USB

La première fois, le navigateur (Chrome ou Edge) demande de **choisir le port** de l'imprimante. Choisissez-la : les tickets suivants partent directement.

## Sans imprimante thermique

MonPOS ouvre une petite fenêtre avec le ticket et un bouton **Imprimer** vers l'imprimante normale de l'ordinateur.

<Info>
  Le ticket ne s'imprime pas tout seul : appuyez sur **Imprimer** quand le client en veut un. Pour une **facture A4** ou pour **l'envoyer sur WhatsApp**, passez par [Ventes](/ventes/historique).
</Info>
