## La barre du haut

| Élément | À quoi il sert |
|---|---|
| Titre de la page | Où vous êtes |
| **POS** (bouton vert au centre) | Ouvre la caisse pour vendre |
| 🔔 Cloche | Les [notifications](/administration/notifications) (ex. stock faible) |
| **EN / FR** | Change la langue |
| Votre nom | Ouvre votre menu : Paramètres, Utilisateurs, Journal d'activité (selon vos droits), **Masquer les images**, **Se déconnecter** |

<Tip>« Masquer les images » enlève les photos des produits partout. Utile sur un téléphone ou une connexion lente.</Tip>

## Le menu de gauche

Vous ne voyez que ce que votre [rôle](/demarrer/roles) permet. Dans l'ordre :

| Menu | Pour |
|---|---|
| Tableau de bord | Les chiffres de la période en un coup d'œil |
| Ventes | Retrouver, imprimer, corriger ou rembourser une vente |
| Échantillons | Marchandise donnée gratuitement |
| Achats | Ce que vous recevez des fournisseurs |
| Produits | Les articles, prix, catégories, étiquettes |
| Stock | Niveaux, mouvements, inventaire, ajustements, transferts |
| Créances | Les factures pas encore payées |
| Dépenses | Loyer, électricité, transport… |
| Postes | Ouvrir et fermer la caisse, voir les écarts |
| Contacts | Clients et fournisseurs |
| Promotions | Remises programmées |
| Clôture du jour | Le bilan d'une journée |
| Rapports | Ventes, stock, crédit, résultat net, valeur du stock |
| Caisse | L'argent dans chaque poche : espèces, Wave, Orange Money… |

Sur ordinateur, la flèche **◀** en haut du menu le replie. Sur téléphone, le bouton ☰ l'ouvre.

<Note>
  Si votre boutique n'a qu'**une seule boutique**, son nom n'apparaît nulle part : pas de sélecteur, pas de colonne. Dès qu'il y en a deux, chaque écran demande ou affiche la boutique.
</Note>
