Menu **Rapports → Résultat net**. Période : ce mois, mois dernier, trimestre, année, 12 mois, ou personnalisée.

## Le calcul

| | |
|---|---|
| Ventes (hors taxe) | |
| **−** Coût de la marchandise vendue | ce que les articles vendus vous avaient coûté |
| **= Marge brute** | avec le % |
| **−** Dépenses | loyer, salaires, transport… |
| **= Bénéfice net** ou **Perte nette** | |

MonPOS le compare à la **période précédente** de même durée.

En dessous :

- **Où sont partis les frais** : par catégorie, récurrent ou ponctuel ;
- un tableau **mois par mois** ou **jour par jour** ;
- **Imprimer** et **CSV**.

<Info>
  **Les achats de stock ne sont pas des dépenses.** Un article acheté compte dans le coût le jour où il est **vendu**, pas le jour où il est acheté. Les ventes annulées sont exclues.
</Info>

<Note>Le coût d'un article est le **coût de revient de son dernier achat reçu**, frais d'achat compris.</Note>
