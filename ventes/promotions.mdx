Menu **Promotions** → **Créer une promotion**.

| Champ | |
|---|---|
| Nom de la promotion | Ex. « Fête des mères » |
| Type | **Remise en pourcentage**, **Remise d'un montant fixe** ou **Achetez X obtenez Y gratuit** |
| Valeur | Le % ou le montant |
| Qté min | Nombre d'articles minimum dans le panier |
| Qté à acheter / Qté offerte | Pour « achetez X obtenez Y » |
| Date de début / de fin | La période où elle est proposée |

Puis **Créer la promotion**.

La liste montre le **statut** : Actif, À venir, Expiré ou Désactivé. **Désactiver / Activer** la met en pause, **Supprimer** l'efface.

<Info>
  Une promotion ne s'applique pas toute seule : le caissier la **choisit** dans la caisse, une par vente. Voir [Remises et promotions](/caisse/remises-et-promotions).
</Info>
